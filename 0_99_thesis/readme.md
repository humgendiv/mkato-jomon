## 各画像の補足説明、わかること（各figureのパスは、./figure以降のパスを参照）
- 1 PCA: 高カバレッジの縄文人ゲノムが、1240Kの縄文人サンプルのクラスターと重なりつつも、さらに密集したクラスターを形成している。縄文人集団の多様性の低さを示唆する。
- 2a~2d admixture: 縄文人集団は、単一成分の集団として認識される。時代を通じて外部から大規模な他集団の移入がなかったという従来の主張を支持する。
- 3a,3b~3f pairwise_f3: 居家以縄文人と他の縄文人集団の間にわずかながら有意な変化が見られる。各都道府県別の現代日本人集団との比較を行うと、縄文人集団は、地域的に分化していたというよりもむしろ、時間的な多様性の近縁のほうが現代日本人との距離を論じるうえでは重要であることを示唆する。
- 4a　f4, 4b　f4_ratio: 現代日本人集団に対する近縁性において、居家以縄文人と他の一部の縄文人集団の間にわずかながら有意な変化が見られる。縄文早期から前期にかけて、現在に至る日本列島の温暖化が確定し、縄文人の生活様式が安定的に推移していったことが、縄文人集団の変化に寄与した可能性がある。
- 6　treemix: 縄文人クラスターが、各サンプルの時代的な変化を示すことができる。縄文人集団の多様性は、地域的に分化よりも時間的な変化のほうが重要であることを示唆する。
- 7a~7c PRS: 縄文人のポリジェニックスコアは、体格、心臓関連、代謝関連、免疫関連の形質で現代日本人集団の平均値と乖離が見られた。現代日本人集団に比較して、縄文人集団は身長が低く、BMIは遺伝的に高い傾向が見られた。代謝関連の形質も軒並みスコアが高く、これらは食糧確保が農耕生活に比べて不安定であった縄文人の狩猟採集生活に起因sるという過去の研究を支持する結果である。栄養状態が現代に比べて不良だったことは、肝機能に関するスコア（Alb,AG）がやや低いことからも示唆される。免疫関連の形質は、多くが現代日本人集団に比べて低スコアとなった。ただし例外的に好中球とWBC総数は好スコアとなり、細菌感染に対する即座の炎症反応能力が高いことを示唆している。一方好酸球、好塩基球は低スコアで、農耕生活によってもたらされる寄生虫感染リスクが縄文時代にはさほど高くなかったことを示唆している。以下AIの補足：心血管系の解釈追加
現在「心臓関連で乖離」とだけ記述されていますが、具体的なパターンを追記すべきです：心機能指標（EF, FS）が低スコア → 現代的な心疾患リスクは低い
心構造指標が様々 → 身体活動量の違いを反映している可能性
重要な補足
3. 腎機能の言及
グラフでは腎機能指標（ターコイズ）も顕著な違いを示しています：

eGFRが高スコア → 腎機能良好
電解質バランス → 高タンパク食（狩猟）への適応を示唆

4. 代謝系の詳細
「代謝関連が軒並み高スコア」について、もう少し具体的に：

脂質代謝（TC, TG, LDL-C高、HDL-C低）→ エネルギー貯蔵能力の向上
糖代謝（BS, HbA1c高）→ 血糖維持能力、飢餓耐性
これらは「倹約遺伝子仮説」を支持

5. 肝機能の解釈修正
「栄養状態不良」というより：

肝酵素（GGT, AST, ALT）が高スコア → 解毒・代謝能力の向上
アルブミン系が低スコア → 現代的な栄養状態とは異なる適応

追加すべき視点
6. 進化医学的意義
これらの違いは現代人の疾病リスクとの関連で重要：

代謝症候群: 縄文人型の代謝は現代の飽食環境では不利
自己免疫疾患: 現代的な免疫バランスの変化と関連
心血管疾患: 現代的なリスクファクターへの感受性の違い
