# 論文要約：各解析で何がわかったか

## 研究概要
古典マヤ期（250-950年CE）のコパン遺跡から発見された7個体の古代ゲノム解析により、マヤ地域の人口動態と遺伝的変化を解明した研究。

## 主要な解析結果

### 1. 古代DNA抽出・品質評価
**解析内容**：16個体から7個体のゲノム抽出・シーケンス、品質評価
**わかったこと**：
- 7個体すべてが古典マヤ期（250-830年CE）に属することを確認
- 内在性DNA含有量1%以上、現代人汚染<1.09%で高品質
- ハプログループはA2/C1（mtDNA）、Q1b（Y染色体）でアメリカ大陸典型的系統
- CpM13（富指定スコア5）は支配王朝メンバーの可能性、CpM12は犠牲埋葬個体

### 2. 人口構造解析（MDS、ADMIXTURE）
**解析内容**：多次元尺度法とADMIXTURE解析による遺伝的クラスター分析
**わかったこと**：
- 古典期コパンは現代マヤと最も近い遺伝的親和性を示す
- 中央アメリカ人口（ベリーズ後期アルカイック、チチェン・イツァ終末期古典、植民地マヤ、現代マヤ）と共通クラスター形成
- K=9のADMIXTURE解析で、後期マヤ人口にアリドアメリカ系統成分（黄色）が出現
- 前期完新世・後期アルカイック個体では地域系統成分（赤色）が最大

### 3. 遺伝的親和性解析（f4統計）
**解析内容**：f4統計によるマヤ地域人口間の遺伝的関係性評価
**わかったこと**：
- 古典期コパンは現代マヤ（1位）、チチェン・イツァ（2位）と最強の遺伝的親和性
- マヤ地域では後期アルカイック期から現在まで遺伝的連続性が存在
- 後期マヤ人口は高地メキシコ人口（オアハカのサポテク、ミヘ、ミステク）と有意な親和性
- 前期完新世個体は後期アルカイックとより強い親和性（高地メキシコ系統流入前）

### 4. IBD解析とコミュニティ検出
**解析内容**：Identical-by-descent（IBD）セグメント解析とネットワーククラスタリング
**わかったこと**：
- 324古代個体中、マヤ地域個体の90%（41個体中36個体）が単一コミュニティ「1-1」を形成
- 地理的・文化的文脈を反映したクラスタリングパターン
- マヤ地域内での長期間にわたる遺伝的結束の証拠

### 5. 混血モデリング解析（qpAdm）
**解析内容**：後期アルカイックを地域系統、サポテクを高地メキシコ系統とした混血モデル
**わかったこと**：
- 古典期コパン：後期アルカイック系統93.9%、高地メキシコ系統6.1%
- チチェン・イツァ終末期古典：両系統がほぼ等比率（約50%ずつ）
- 植民地期：チチェン・イツァと類似の比率維持
- 現代マヤ：後期アルカイック系統76.5%に回復（サンプルサイズ小による可能性）
- 地理的勾配：南（コパン）から北（チチェン・イツァ）で高地メキシコ系統増加

### 6. 混血時期推定（DATES）
**解析内容**：チチェン・イツァ個体での混血時期をDATES法で推定
**わかったこと**：
- 後期アルカイックと高地メキシコ系統の混血は497±159年前（チチェン・イツァ個体年代基準）
- 892年CE（チチェン・イツァ平均年代）から逆算すると、混血は前期-中期古典期（395年CE頃）に発生
- 混血タイミングはマヤ文明の政治的発展期と一致

### 7. 人口サイズ変動解析（IBDNe）
**解析内容**：IBDセグメント共有パターンから有効人口サイズの時間変動を推定
**わかったこと**：
- マヤ地域人口は約1,221年BP（829年CE）に約19,000でピークに達成
- 人口増加は高地メキシコ系統流入と農業発達（トウモロコシ依存）に関連
- 約1,200年BP（850年CE）から急激な人口減少開始
- 人口減少は古典マヤ文明崩壊（9-11世紀CE）・深刻な干ばつと時期的に一致
- 他地域（チャネル諸島、パタゴニア）と比較してマヤ地域の人口変動が顕著

### 8. 同位体分析との統合
**解析内容**：既存の歯エナメル同位体データとの比較
**わかったこと**：
- 同位体分析で示された広範囲移動性を遺伝的データが支持
- 特にエリート層での非地域起源を確認
- 遺伝的解析により第一世代を超えた長期的遺伝子流動を検出可能

## 研究の意義

### 考古学的意義
- コパン王国形成におけるマヤエリートネットワークの役割を遺伝的に実証
- 地域人口と外来エリートの融合による政体拡大戦略を支持
- 文明崩壊時期の人口減少を遺伝的に確認

### 方法論的意義  
- 低カバレッジ古代ゲノムでの統計解析手法の有効性を実証
- IBD解析による古代人口動態復元の新手法
- 混血モデリングによる遺伝子流動時期・規模の定量的評価

### 限界と今後の課題
- サンプルサイズの制約（7個体のみ）
- 地理的・時間的サンプリングの偏り
- 富指定スコアの考古学的文脈との不一致
- より広範囲・高密度なサンプリングの必要性
